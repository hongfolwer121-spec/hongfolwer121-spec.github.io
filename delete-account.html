계정 및 데이터 삭제 방법

앱: 핑퐁딜 (PINGPONG DEAL) · 개발자: Hide on house

핑퐁딜은 이메일·비밀번호 없이 닉네임만으로 기기별 계정이 만들어집니다. 아래 방법으로 언제든 계정과 데이터를 삭제할 수 있습니다.

방법 1. 앱에서 바로 삭제 (즉시 처리)

  1. 핑퐁딜 앱을 엽니다.
  2. 홈 화면 오른쪽 위 ⋮ (더보기) 메뉴를 누릅니다.
  3. 맨 아래 「내 정보 삭제」를 누릅니다.
  4. 확인 창에서 「모두 삭제」를 누르면 즉시 삭제됩니다.

방법 2. 이메일로 삭제 요청 (앱을 지웠거나 기기를 바꾼 경우)

  1. hongfolwer121@gmail.com 으로 메일을 보냅니다. (제목: [핑퐁딜] 계정 삭제 요청)
  2. 본문에 닉네임과, 확인을 위해 등록했던 상품명 또는 대화했던 상대 닉네임 중 하나를 적어 주세요.
  3. 확인 후 7일 이내에 삭제하고 회신드립니다.

삭제되는 데이터

  • 닉네임과 기기별 익명 계정
  • 내가 올린 상품, 상품 사진, (선택) 추가 연락처
  • 모든 채팅방과 대화 내용
  • 푸시 알림 토큰, 알림 설정, 차단 목록

보관되는 데이터와 기간

  • 서버 접속 기록(IP 주소, 접속 시각): 보안 목적으로 최대 90일 보관 후 자동 삭제
  • 관심 카테고리·최근 검색어: 서버에 저장되지 않고 기기에만 있으므로, 앱을 삭제하면 함께 지워집니다.
  • Google AdMob이 처리하는 광고 데이터는 Google 정책에 따릅니다.

일부 데이터만 삭제하기

  • 상품: 상품 화면 ⋮ 메뉴 → 「삭제」 또는 「판매완료」 (상품·사진·관련 채팅 삭제)
  • 채팅: 채팅방 ⋮ 메뉴 → 「채팅방 나가기」 (두 사람 모두 나가면 대화 내용 삭제)
